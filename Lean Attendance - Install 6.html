Lean Attendance

Worked hours, average and balance from erp.lean.sa: Windows and Mac, any browser

⏱ Lean Attendance
Drag this button to your bookmarks bar. Don't click it here: it only works on erp.lean.sa.

Install (one time)

  1. Show the bookmarks bar: Ctrl+Shift+B on Windows, ⌘+Shift+B on Mac.
    In Edge it's called the favorites bar.
  2. Drag the blue ⏱ Lean Attendance button above onto the bar.
  1. Show the Favorites bar: View → Show Favorites Bar (⌘+Shift+B).
  2. Drag the blue ⏱ Lean Attendance button above onto the Favorites bar.
  3. If clicking it later does nothing: Safari → Settings → Advanced, tick Show features for web developers, then in Develop turn on Allow JavaScript from Smart Search Field.
  1. Show the bookmarks toolbar: Ctrl+Shift+B on Windows, ⌘+Shift+B on Mac.
  2. Drag the blue ⏱ Lean Attendance button above onto the toolbar.

Can't drag? Click Copied ✓
then add a new bookmark, name it Lean Attendance, and paste into its URL / address field.

Use

  1. Open erp.lean.sa and sign in as usual (Microsoft).
  2. Click ⏱ Lean Attendance in your bookmarks bar.
  3. Pick one or more months. Close with Esc or ×.

Alternative without a bookmark: on the ERP page open the browser console (F12 on Windows, ⌥+⌘+J on Mac), click Copied ✓, paste it into the console and press Enter.

How it calculates

  • Working day = a Sunday–Thursday row in your attendance table → 8 hours required.
  • WFH (Work From Home) counts as a full 8-hour working day.
  • Not required: Friday & Saturday, approved leaves (from your Leave page), Leave and Public Holiday days. Hours worked on those days count as extra.
  • Absence / No Show / a day with 00:00 still require 8 hours.
  • Today is not included.
  • Balance = total worked − required. Average = total worked ÷ working days.

Privacy: it runs only in your own browser, reads only your own ERP pages, and sends nothing anywhere. To open faster, it keeps a copy of your last results in this browser (for erp.lean.sa only).

Tip: click it while you're on the attendance page. It then reads the data already on screen instead of downloading it again.

Windows desktop app (optional)

Windows users can instead run Windows app\LeanAttendance.exe from this folder: same calculation, with its own sign-in window. No install needed. If Windows shows "Windows protected your PC", click More info → Run anyway.
